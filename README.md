## Descripción

Este proyecto demuestra, en un entorno local y controlado, una vulnerabilidad de inyección SQL y su mitigación mediante consultas parametrizadas y verificación segura de contraseñas.

También incluye un escáner básico de puertos locales y un módulo de revisión de aspectos de seguridad de SQLite.

## Tecnologías utilizadas

- Python
- Flask
- SQLite
- Werkzeug
- Visual Studio Code
- Git y GitHub

## Archivos principales

- `app_vulnerable.py`: aplicación vulnerable de demostración.
- `app_segura.py`: aplicación corregida.
- `ataque_sql_i.py`: script de prueba SQL Injection.
- `escaneo_red.py`: escaneo básico de puertos locales.
- `seguridad_bd.py`: revisión básica de seguridad de la base de datos.
- `MANUAL_USO.md`: instrucciones de instalación y ejecución.

## Ejecución

Consulta el archivo `MANUAL_USO.md` para conocer los pasos de instalación y ejecución.

## Uso académico

Todas las pruebas se realizaron en un entorno local controlado con fines educativos. No se deben ejecutar pruebas contra sistemas sin autorización.
